# 본문 이미지 저작 가이드

아티클 md의 이미지 문법과 렌더 규칙. 변환은 `src/plugins/rehypeImgToFigure.ts`가 담당한다.

## 기본 — 캡션

```md
![캡션이 되는 alt](assets/photo.png)          ← 단독 이미지: alt가 캡션으로

![대체 텍스트](assets/photo.png)
이미지 아래 연속 줄 텍스트가 캡션.            ← 연속 줄: 이 텍스트가 캡션(alt는 SR용으로 유지)
여러 줄을 쓰면 전부 캡션에 포함된다.

본문 문단 끝.
![alt 캡션](assets/photo.png)                 ← 본문에 붙여 써도 됨(문단 자동 분할)
```

- 캡션과 본문의 경계는 **빈 줄** — 캡션 다음 빈 줄을 꼭 둘 것
- `![](...)` 빈 alt = 장식 이미지: 캡션 없음, figure 승격 없음
- 문장 속 인라인 이미지(줄바꿈 없이 텍스트와 병기)는 변환하지 않는다

## 크기 조절

```md
![도면|400](assets/photo.png)        ← 표시 폭 400px (Obsidian 리사이즈 문법 호환)
![도면|400x300](assets/photo.png)    ← 높이값은 비율 붕괴 방지를 위해 무시됨
```

`width: min(100%, 400px)`로 적용되어 모바일에서 자동 축소. srcset·원본 해상도는 그대로다.
폭 힌트는 **2~4자리(10–9999px)만 인정** — `|2`처럼 한 자리 수로 끝나는 alt는 힌트가 아니라 본문으로 취급된다.

## 나란히 배치

```md
![왼쪽 캡션](assets/a.png) ![오른쪽 캡션](assets/b.png)   ← 같은 줄 = 가로 균등 배치, alt가 각자의 캡션으로

![왼쪽](assets/a.png) ![오른쪽](assets/b.png)
나란히 놓인 두 이미지의 공동 캡션.                 ← 다음 줄 텍스트 = 공동 캡션(이때 alt는 SR 전용)
```

같은 줄에 쓴 개수만큼 균등 분할(flex). 3개 이상도 가능하나 카드 폭을 고려할 것.
캡션 규칙은 단독 이미지와 동일 — 다음 줄 텍스트(공동)가 있으면 그것이, 없으면 각 이미지의 alt가 캡션이 된다.
`![](...)` 빈 alt 셀은 캡션 없이 이미지만. **모바일(<768px)에서는 세로 한 줄로 쌓인다.**

## 글과 나란히 (랩 배치)

```md
![도면 캡션|300|left](assets/chart.png)

이 문단부터 이미지의 오른쪽을 감싸며 흐른다. |right는 반대 방향.
힌트 순서는 무관(|left|300도 동일)이고 폭 힌트를 생략하면 45% 폭이 상한.
```

이미지 단독 줄 + `|left`/`|right` 힌트 → 뒤따르는 문단이 이미지를 감싼다(캡션 규칙은 동일하게 작동).
모바일(<768px)에서는 플로트가 풀려 이미지 위·글 아래로 자연 스택. 다음 헤딩(h1~h6)은 항상 플로트 아래에서
시작하므로 랩이 섹션 경계를 넘지 않는다.

## 함정 두 가지

1. **Obsidian 위키링크(`![[...]]`)는 렌더되지 않는다** — 이관 시 표준 문법으로 바꾸고
   이미지 파일을 포스트의 `assets/`로 복사해야 한다(볼트 참조는 리포에 없음).
2. **dev 실행 중 이미지 파일을 추가하면 안 보인다**(콘텐츠 레이어 stale — 이미지가
   JSON 텍스트로 새거나 구버전이 나옴) — `pnpm run dev:fresh`로 재기동하면 해결.
